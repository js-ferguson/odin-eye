>
  Retrieve what each character's OdinEye.Client has reported about itself
</h1>

<MethodEndpoint
  method={"get"}
  path={"/players/meta"}
>
  
</MethodEndpoint>



Returns the `Meta` (`PlayerId`, `ClientVersion`) last submitted alongside
each character's stats (see `POST /players/{id}/stats`), keyed by
player ID (see `Player.Id` under `GET /players`). A separate endpoint
from `GET /players/stats` so that one's own response shape never
changes. In memory only -- cleared on restart.
