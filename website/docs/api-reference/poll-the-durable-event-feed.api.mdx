  className={"openapi__heading"}
>
  Poll the durable event feed
</h1>

<MethodEndpoint
  method={"get"}
  path={"/events"}
>
  
</MethodEndpoint>



Returns events with a sequence number greater than `after`, oldest
first, up to `limit`. See [Events > GET /events](/docs/events/intro)
for the full explanation of `BootId`/`Seq`/`Gap` and how this relates
to the WebSocket stream. Chat messages are never included.
