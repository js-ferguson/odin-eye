<h1
  className={"openapi__heading"}
>
  Submit a character's stats
</h1>

<MethodEndpoint
  method={"post"}
  path={"/players/stats"}
>
  
</MethodEndpoint>



Accepted only from a currently connected player (`{id}`, see
`Player.Id` under `GET /players`). Every value must be non-negative,
finite, plausible for elapsed real time since Valheim's release, and
**no lower than the value already held for that same key** -- the
whole submission is rejected (nothing is applied) if even one value
fails any of these checks. `Stats` is an open, arbitrary key set on
purpose: whatever the submitting OdinEye.Client reports is stored as
given, with no fixed schema, so a new stat key (including ones a future
Valheim version adds) needs no change here.
