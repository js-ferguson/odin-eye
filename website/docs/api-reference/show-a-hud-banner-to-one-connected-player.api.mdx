<h1
  className={"openapi__heading"}
>
  Show a HUD banner to one connected player
</h1>

<MethodEndpoint
  method={"post"}
  path={"/players/{steamId}/notify"}
>
  
</MethodEndpoint>



Shows a brief message centered on screen to exactly one currently
connected player, using Valheim's own `MessageHud` "ShowMessage" routed
RPC -- this works for **every** player, whether or not they have
OdinEye.Client installed. POST-only: there's no state to read back.
