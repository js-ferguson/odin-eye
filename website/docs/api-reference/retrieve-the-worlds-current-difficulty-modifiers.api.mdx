<h1

>
  Retrieve the world's current difficulty modifiers
</h1>

<MethodEndpoint
  method={"get"}
  path={"/worldModifiers"}
>
  
</MethodEndpoint>



Returns the world's current difficulty settings (combat, death penalty,
resources, raids, portals) -- read-only. OdinEye does not accept writes to
these; use a separate RCON-capable mod (e.g. Tristan/ValheimRcon) to change
them via Valheim's own `setworldmodifier`/`setworldpreset` console commands.

A category reports `"default"` when nothing has ever customized it,
`"unknown"` when the world's raw settings don't parse into individual
categories (this happens right after a *named preset*, e.g. `hardcore`, was
applied with `setworldpreset` -- in that case `Summary` names the preset
instead), or the real value otherwise.
