<h1
  className={"openapi__heading"}
>
  Report client-observed events
</h1>

<MethodEndpoint
  method={"post"}
  path={"/players/{id}/events"}
>
  
</MethodEndpoint>



Lets an installed OdinEye.Client report the few things only a player's
own machine can observe. Every accepted event is attributed to `{id}`
(taken from the URL, never from the request body) and enters the same
feed `GET /events` and the WebSocket stream serve -- see
[Event types](/docs/events/event-types) for what each `Type` means and
its `Data` fields.

The whole batch is validated together and either fully accepted or
fully rejected: at most 20 events per request, `Type` must be one of
the allowed values, and every field is checked (player IDs must be
whole numbers, coordinates must be finite and within the game's
plausible world bounds). Rate limited to 20 events per player per
minute.
