>
  Retrieve live cheat-detection status
</h1>

<MethodEndpoint
  method={"get"}
  path={"/players/cheatStatus"}
>
  
</MethodEndpoint>



Returns every character's last-reported cheat status, keyed by their
player ID (see `Player.Id` under `GET /players`). In memory only, like
every other live-state endpoint here -- cleared on restart. Reported by
an installed OdinEye.Client; a character running without it simply has
no entry.
