  Submit a character's cheat-detection status
</h1>

<MethodEndpoint
  method={"post"}
  path={"/players/cheatStatus"}
>

Overwrites the stored status for `{id}` with exactly what's submitted --
unlike `POST /players/{id}/stats`, there is no "never lower than before"
validation, since this flag must be able to flip back to `false` the
instant a player drops a flagged item. `{id}` must currently be
connected (see `Player.Id` under `GET /players`).
