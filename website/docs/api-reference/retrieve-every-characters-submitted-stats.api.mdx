<h1

>
  Retrieve every character's submitted stats
</h1>

<MethodEndpoint
  method={"get"}
  path={"/players/stats"}
>
  
</MethodEndpoint>



Returns every character's stats last submitted by their OdinEye.Client,
keyed by player ID (see `Player.Id` under `GET /players`). In memory
only -- cleared on restart. A character that has never run
OdinEye.Client, or hasn't submitted since the last restart, simply has
no entry.
